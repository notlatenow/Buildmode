# BUILDMODE 2026 Submission Checklist

The whole team should complete the following checks at least 30 minutes before the deadline.

## Team Information

- [ ] Team number, team name, members, and primary contact are correct
- [ ] A main track has been selected
- [ ] Only Sponsor Challenges/Bounties you actually qualify for are checked
- [ ] Project name and 100–200 word summary have been proofread

## Code & Documentation

- [ ] GitHub/GitLab repository can be opened directly in an incognito window
- [ ] Repository contains recognizable, working implementation
- [ ] README includes problem, features, architecture, tech stack, how to run it, and limitations
- [ ] A clear LICENSE file has been added
- [ ] Sources and licenses for third-party packages, models, data, and assets are disclosed
- [ ] No API keys, tokens, passwords, or personal data in the repository

## Demo & Video

- [ ] If a demo URL is provided, confirmed it opens directly in an incognito window
- [ ] README provides complete installation and setup instructions
- [ ] Judging video is no longer than 2:00
- [ ] YouTube video is set to "Anyone with the link can view"
- [ ] Video audio, captions, and visuals play correctly
- [ ] A local backup video or screenshots are prepared

## Before Submitting

- [ ] All form links have been reopened and tested
- [ ] A screenshot or confirmation email of successful submission has been kept
- [ ] Time has been reserved before the deadline to handle any link or permission issues
